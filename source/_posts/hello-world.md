欢迎来到我的技术笔记！

这是博客的第一篇文章。本站基于 [Hexo](https://hexo.io/) + [Butterfly](https://butterfly.js.org/) 搭建，托管在 GitHub Pages 上。

## 这里会写什么

- 嵌入式开发笔记（MPLAB、LTspice、单片机）
- Python 与控制理论学习
- 折腾过程中的踩坑记录

## 如何发布新文章

```bash
hexo new post "文章标题"   # 新建文章
hexo server               # 本地预览 http://localhost:4000
git add -A
git commit -m "new post"
git push                  # 推送到 GitHub，自动部署
```
