内模控制（Internal Model Control, IMC）的核心思想：**控制器中嵌入过程的数学模型**。

## 基本结构

```
        Q(s)                G(s)
r --->[IMC]---+--> u --->[过程]---+---> y
              |                  |
              +----[Gm(s)模型]<--+
```

## 关键公式

等价经典反馈控制器：

$$C(s) = \frac{Q(s)}{1 - Q(s)G_m(s)}$$

对于一阶惯性+时滞过程 $G(s) = \frac{K}{\tau s+1}e^{-\theta s}$：

- $Q(s) = \frac{\tau s+1}{K} \cdot \frac{1}{\lambda s+1}$
- IMC-PID 参数：$K_c = \frac{\tau}{K(\lambda+\theta)}$，$T_i = \tau$

## Python 仿真代码

```python
import control as ct
import numpy as np

K, tau, theta = 2.0, 5.0, 1.0
lam = 1.0  # 滤波器时间常数

G = ct.tf([K], [tau, 1])
Q = ct.tf([tau, 1], [K]) * ct.tf([1], [lam, 1])
T = G * Q  # 模型准确时的闭环传递函数

t, y = ct.step_response(T)
```

## 心得

- λ 越小跟踪越快，但对模型失配越敏感
- λ 越大越鲁棒，但响应变慢
- 经验取值：$\lambda \in [\theta, 3\theta]$
